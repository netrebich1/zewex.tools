## Откуда берётся ухудшение

1. **Сам перевод (главная причина).** Исходники уже отредактированы: короткая фраза, глагол действия, точный термин,
   голос автора. Три перевода превращают это в развёрнутый нейтральный текст: «Рукавички потрібні від першого мазка» →
   «необхідно носити рукавички», «проте не кричить» → «не виглядаючи при цьому надто кричущим».
2. **Потеря терминов и предмета статьи** (этап DE→UK): світшот → «светр / кофта / футболка», черевики → «чоботи»,
   джинси мом → «Мами обирають штани», «Главред» → «Головна редакторка», комір-хомут → «некхолдер / кауль»,
   ранер → «оформлення зеленими рослинами», підбір (каблук) → «вибір взуття».
3. **Перевёрнутый смысл:** «розбиває верх» → «розширює верхню частину тіла»; «утрамбований на літо в шафу» →
   «яку все літо можна лишити вдома»; «2 ковпачки рідкого засобу» → «рідини для посуду»;
   «вологий пух не відчувається пальцями» → «ви більше не відчуватимете вологого наповнювача».
4. **Фразы вокруг ссылок.** Текст ссылки заморожен, а предложение вокруг переведено: «погляньте на [як перевірити…]»,
   «як у цих [відкриті шви…]», дубли «…ретро-світшота, які називає … ретро-світшота…». Часть ломает DeepL, часть —
   постредактура при починке.
5. **Технический брак:** ссылки навигации переехали в абзац на этапе «Стиль» (статьи 3 и 8, исправлено кодом 05.11),
   `&#x27;` вместо апострофа (DE→UK), сбои на «ти» («Прив’яжи», «виділи»), H2 не по разделу.

«при» → «за», «кружка» → «чашка», «підбірка» → «добірка», «в підлогу» → «до підлоги», «2–4 гостей» → «2–4 гості»,

корректорской вычитки, и его можно получить без трёх переводов.

## Что предлагается

1. **Предложения со ссылками брать из исходника целиком** (сейчас заморожен только текст ссылки). Снимает весь класс
   сломанных фраз и дублей у ссылок.
2. **Списки-шаги, таблицы и подписи к фото не переводить.** В них цифры, предметы и действия; «паттернов» там нет,
   а ошибок перевода больше всего.
3. **Замок на термины.** Ключевые существительные исходника (предмет статьи, названия деталей, изданий, имён) должны
   стоять в итоге в том же виде; подмена — возврат слова кодом.
4. **Этап «стиснення» вместо нынешнего «Стиля».** Правка по списку конструкций перевода («оскільки» → «бо»,
   «тоді як» → «а», «слід + інф.» → повелительное, «протягом N» → N, лишние «цей / ваш / свій», «з використанням»,
   «завдяки чому», «що є») с бюджетом длины: итог не длиннее исходника более чем на 3 %. Формулировки исходника
   при этом не возвращаются.
5. **Сверка фактов по предложениям.** Оценщик сравнивает итог с исходником попарно и отдаёт на правку только
   предложения с расхождением смысла, числа, предмета, адресата.
6. **Проверить цепочку из двух переводов (UK→EN→UK)** на 3–4 статьях: немецкий шаг даёт именной стиль
   («при температурі», «з використанням») и основную часть подмен.
7. **Оценщик:** сравнивать с исходником как с эталоном и считать маркеры перевода и прирост длины.

Цена вопроса: пункты 1 и 2 поднимут совпадение с исходником примерно с 12,6 % до 25–30 %. Это решение владельца.
