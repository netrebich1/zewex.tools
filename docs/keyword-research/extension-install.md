# Расширение «Zewex Collector»: установка и работа

Расширение снимает выдачу Pinterest и частотность Ads Manager для инструмента «Подбор ключей» (zewex.tools → Pinterest → Подбор ключей). Оно работает в том браузере Chrome, где вы вошли в аккаунт Pinterest. Mac и Windows — одинаково.

Одно расширение = один браузер (профиль Chrome) = один аккаунт Pinterest. Для второго аккаунта (например, W) нужен второй профиль Chrome со своим расширением и своим токеном.

## 1. Скачать расширение

1. Откройте zewex.tools → Pinterest → «Подбор ключей» → вкладка **«Сбор»**.
2. В карточке «Расширения» нажмите **«Скачать расширение (ZIP)»**.
3. Распакуйте архив (двойной щелчок по файлу `zewex-collector.zip`). Появится папка **`zewex-collector`**. Положите её туда, где она будет лежать постоянно (например, в «Документы»): удалять папку после установки нельзя.

## 2. Установить в Chrome

1. В адресной строке Chrome наберите `chrome://extensions` и нажмите Enter.
2. Справа вверху включите переключатель **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `zewex-collector` (саму папку, в которой лежит `manifest.json`).
4. В списке появится «Zewex Collector». Нажмите на значок пазла справа от адресной строки и закрепите «Zewex Collector» (булавка), чтобы его кнопка была всегда видна.

## 3. Выдать токен и подключить

1. На вкладке «Сбор» в карточке **«Выдать токен»** выберите аккаунт Pinterest, который открыт в ЭТОМ браузере (например, «SEO Netrebich»), и нажмите **«Выдать токен расширению»**.
2. Нажмите **«Скопировать»** — токен показывается только один раз.
3. Нажмите кнопку расширения «Zewex Collector» в Chrome, вставьте токен в поле, оставьте галочку **«Сбор включён»** и нажмите **«Сохранить и проверить»**. Должна появиться зелёная строка «Подключено: аккаунт …».

Если аккаунта ещё нет в списке — добавьте его на вкладке «Сбор» внизу карточки «Аккаунты Pinterest» («Новый аккаунт Pinterest» → «Добавить»).

## 4. Запустить сбор выдачи

1. На вкладке «Сбор» в карточке **«Поставить в очередь»** выберите «Выдачу Pinterest», сколько ключей, и нажмите **«В очередь»**. Можно и с экрана «Ключи»: кнопка **«В очередь: выдача»** ставит все ключи под текущими фильтрами; в раскрытой строке ключа есть **«Снять выдачу заново»**.
2. Откройте в этом браузере вкладку **www.pinterest.com** (вы должны быть в аккаунте). Оставьте её открытой — сбор идёт на ней сам. Можно работать в других вкладках; лучше не закрывать окно с этой вкладкой и не сворачивать компьютер в сон.
3. Ход работы видно в окне расширения (кнопка «Zewex Collector») и на вкладке «Сбор» → «Расширения» → «Что делает». Значок расширения: **ON** — работает, **!** — Pinterest отказал или есть ошибка.

Темп: между ключами пауза из настроек аккаунта (по умолчанию 10 с, со случайным разбросом 8–15 с). Если Pinterest отвечает пустой выдачей или ошибкой, расширение само делает паузы 2 → 4 → 8 → 15 минут. Если и после этого отказы, аккаунт помечается «Ограничен поиск» на 4 часа (повторно 8 ч, затем сутки), и задания забирает другой аккаунт. Суточного лимита нет: в карточке «Блоки Pinterest» копится статистика — после скольких ключей начался блок и сколько он длился.

Медленный режим (для W): вкладка «Сбор» → аккаунт → «Настроить» → «Пауза между ключами» 20–30 с → «Сохранить». Там же можно выключить аккаунт (режим «Выключен»), снять ограничение вручную или включить лимит в сутки.

## 5. Частотность (Ads Manager)

1. Поставьте в очередь «Частотность (Ads Manager)».
2. Откройте в том же браузере **ads.pinterest.com**, рекламный аккаунт 549767483773, черновик кампании с таргетингом US, шаг с полем ключевых слов (как при ручном сборе). Кампанию не публикуйте.
3. Расширение само вписывает ключ в поле и берёт точную аудиторию из ответа Ads Manager. Поле при этом меняется — это нормально.

## Если что-то не так

| Что пишет расширение | Что сделать |
|---|---|
| «Вставьте токен в окне расширения» | Шаг 3. |
| «Токен не найден или отозван» | Выдайте новый токен на вкладке «Сбор» и вставьте его. |
| «В браузере открыт @…, а токен выдан для …» | В этом браузере открыт не тот аккаунт Pinterest. Войдите в нужный или выдайте токен для открытого аккаунта. |
| «Не удалось узнать аккаунт Pinterest» | Проверьте, что вход в Pinterest выполнен. Если да — «Сбор» → аккаунт → «Настроить» → впишите логин Pinterest (как в адресе профиля) → «Сохранить». |
| «Пауза после отказа Pinterest…» | Ничего, расширение подождёт само. |
| «Pinterest ограничил поиск…» | Ждём указанное время. Если поиск в браузере уже работает — «Сбор» → «Настроить» → «Снять ограничение». |
| «Откройте черновик кампании…» | Шаг 5.2. |
| «Расширение перезагружено, обновите вкладку» | Обновите вкладку Pinterest (F5 / Cmd+R). |

## Обновление расширения

Когда выйдет новая версия: скачайте ZIP заново, замените содержимое папки `zewex-collector` новыми файлами, откройте `chrome://extensions` и нажмите круглую стрелку «Обновить» у «Zewex Collector», затем обновите вкладку Pinterest. Токен вводить заново не нужно.
