## Как устроено

- Проект = сайт. Расход — с ключей команды проекта (`teamId`) по правилам слотов `news:text_main` и `news:embed`; сид создаёт правила для WexOra, если их нет. `UsageLog.refId` = id прогона.
- Плановый прогон раз в `intervalMin` (40 мин), ручной — кнопкой; `nextRunAt` считается от окончания прогона. Один прогон на проект.
- Google News — по одному запросу с паузой 3–5 с: нишевые запросы проекта + сущности через OR (первый ряд каждый прогон, остальные ротацией `state.gnewsCursor`).
- Фильтры: стоп-слова по началу слова с исключениями; для профильной ленты и при звезде первого ряда в заголовке — только по заголовку, иначе заголовок + первое предложение лида; стоп-рубрики — по первым трём словам рубрики, не для профильных; белый список — сущность, нишевое слово или профильная лента.
- Фильтр по эмбеддингу включается сам, когда наберётся по 40 размеченных LLM примеров «нашего» и «не нашего» за 30 дней.
- Кластер: косинус к центроиду ≥ `clusterSim` (с той же главной сущностью — `clusterSimEntity`), окно 48 ч. Заголовок кластера — первая украинская публикация.
- Лента: топ-N кластеров за сутки по баллу; от `urgentScore` — «Срочно» и Telegram.
- Хранение: отсечённые и дубли — 14 дней, векторы — 30 дней, кластеры и материалы в них — бессрочно.
