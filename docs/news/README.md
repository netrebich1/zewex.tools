## Как устроено

- Проект = сайт. Расход — с ключей команды проекта (`teamId`) по правилам слотов `news:text_main` и `news:embed`; сид создаёт правила для WexOra, если их нет. `UsageLog.refId` = id прогона.
- Плановый прогон раз в `intervalMin` (40 мин), ручной — кнопкой; `nextRunAt` считается от окончания прогона. Один прогон на проект.
- Google News — по одному запросу с паузой 3–5 с: нишевые запросы проекта + сущности через OR (первый ряд каждый прогон, остальные ротацией `state.gnewsCursor`, `gnewsGroupsPerRun` групп по 6 за прогон).
- Редакция Google News берётся из языка источника: `lang: en` — американская (`site:people.com` в украинской редакции пустой), fr/it/de/pl — свои; иначе редакция проекта.
- Сущности: совпадение по основе (кириллица — минус до двух конечных гласных, плюс падежное окончание). Короткий однословный вариант может совпасть с обычным словом («Картьє» → «карт», «Ганні» → «Ганна», «Сумська» → Сумська область): перед добавлением прогонять `alias-audit.ts`, такие варианты давать только полным именем.
- Фильтры: стоп-слова по началу слова с исключениями; для профильной ленты и при звезде первого ряда в заголовке — только по заголовку, иначе заголовок + первое предложение лида; стоп-рубрики — по первым трём словам рубрики, не для профильных; белый список — сущность, нишевое слово или профильная лента.
- Фильтр по эмбеддингу включается сам, когда наберётся по 40 размеченных LLM примеров «нашего» и «не нашего» за 30 дней.
- Кластер: косинус к центроиду ≥ `clusterSim` (с той же главной сущностью — `clusterSimEntity`), окно 48 ч. Заголовок кластера — первая украинская публикация.
- Лента: топ-N кластеров за сутки по баллу; от `urgentScore` — «Срочно» и Telegram.
- Хранение: отсечённые и дубли — 14 дней, векторы — 30 дней, кластеры и материалы в них — бессрочно.

## Известное

- С IP сервера не отдают ленты Обозреватель, People, Business of Fashion, Hypebeast, TMZ, gazeta.ua, depo.ua, СТБ, Суспільне (403). Прямые ленты выключены, вместо них запросы Google News `site:…` (мировые — в американской редакции). С прокси прямые ленты можно включить обратно на вкладке «Источники».
- Выключены как не тема сайта (релизы кроссовок): Sneaker News, Footwear News и запрос Google News по Hypebeast. Последний давал до трети верха ленты даже с весом 0.3.
- Строки лент очищаются от одиночных суррогатов (`wellFormed` в parse.ts): «половинка» эмодзи ломала запись в базу.
- История Discover (GSC) в балле — этап 3; угол, ТЗ, метатеги, черновик WordPress — этап 2.
