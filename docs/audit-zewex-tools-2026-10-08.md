# Аудит: портал zewex.tools (сессия «Миграция сервисов на собственный сервер»)

Дата: 2026-10-08. Объект: код в `~/Projects/zewex-tools` (1 коммит b5241d1), деплой на https://zewex.tools.

## Что проверено
- Весь исходный код портала (схема БД, auth, прокси, правила, страницы, деплой-скрипт, systemd, nginx-include).
- Публичное поведение сайта снаружи: редиректы, ответы API без сессии, заголовки, TLS, HTTP без TLS.
- Эндпоинт моделей Perplexity (прямой запрос).

## Что НЕ удалось проверить
- Состояние сервера (служба, .env, nginx-конфиг FASTPANEL, БД): SSH на продакшен запрещён политикой этой сессии.
- Сборку и проверку типов: на Mac нет Node, в репозитории нет lock-файла, тестов и CI.
- Мобильную вёрстку: сессия сама признала, что скриншот не сняла.

## Соответствие постановке
Все заявленные требования реализованы: закрытая регистрация на одну почту, приглашения, роли, разделы-вкладки, единое хранилище ключей, правила на пяти уровнях (человек+инструмент, команда+инструмент, инструмент, команда, глобально), один ключ во многих правилах, каталог моделей, бэкенд-прокси и учёт расхода. Архитектура соответствует плану v2.

## Находки по убыванию важности

### Критично / высоко
1. **Деплой может молча уничтожить данные.** `deploy/deploy.sh` на каждом выкате выполняет `prisma db push --accept-data-loss`. Любое будущее изменение схемы с удалением или переименованием колонки удалит данные без вопросов, включая зашифрованные ключи. Миграций нет, бэкап БД нигде не настроен и не упомянут.
2. **Сайт отвечает по обычному HTTP без редиректа на HTTPS.** `http://zewex.tools/login` отдаёт 200. Форма входа и пароль могут уйти открытым текстом. HSTS нет.
3. **Сид затирает правки админа при каждом деплое.** `prisma/seed.mjs` делает upsert с `update: { name, baseUrl, docsUrl, order }` для провайдеров и `order` для разделов. Если в интерфейсе изменить адрес laozhang или порядок вкладок, следующий деплой вернёт значения из сида.
4. **Проверка ключа Perplexity всегда падает.** В `src/lib/adapters.ts` `checkKey` при пустом `modelsEndpoint` подставляет `models`. У Perplexity такого эндпоинта нет: `GET https://api.perplexity.ai/models` отвечает 404. Рабочий ключ будет помечен как ошибочный при создании и по кнопке «Проверить».
5. **Месячный лимит срабатывает не всегда, хотя интерфейс обещает блокировку.** Лимит считается по `costUsd`, а стоимость известна только когда у модели заданы цены. У OpenAI `GET /v1/models` цен не отдаёт, у SERP стоимость всегда null. Для таких ключей лимит никогда не сработает.

### Средне
6. **Сборка невоспроизводима.** Нет `package-lock.json`, версии в `package.json` с `^`. Деплой делает `npm install` на сервере и каждый раз может подтянуть другие версии. На Mac нет Node, собрать и проверить локально нельзя.
7. **Код существует в двух копиях без удалённого репозитория.** Один коммит на Mac и rsync-копия на сервере. `git remote` пуст.
8. **Ключ шифрования `APP_ENCRYPTION_KEY` нигде не задублирован (по коду).** Если `.env` на сервере потеряется, все сохранённые API-ключи станут нечитаемыми. Нужно убедиться, что он сохранён вне сервера.
9. **Нет защиты от перебора пароля.** Ни лимита попыток, ни задержки на `/login`, `/invite/*`, `/api/run`.
10. **Нет восстановления доступа для единственного админа.** Забытый пароль владельца лечится только через БД. Страница `/register` остаётся видимой после регистрации.
11. **Сессионная cookie привязана только к хосту `zewex.tools`.** Инструменты на поддоменах не смогут вызывать `/api/run`. Перед переносом сервисов из Lovable нужно решить: монтировать их по путям под zewex.tools или задавать `Domain=.zewex.tools` плюс CORS и проверку Origin.
12. **Нет заголовков безопасности.** Отсутствуют HSTS, X-Frame-Options или CSP frame-ancestors, X-Content-Type-Options. `X-Powered-By: Next.js` раскрывается, `poweredByHeader` не выключен.
13. **Роль «лидер команды» ничего не даёт.** `TeamRole.LEAD` есть в схеме и в интерфейсе, но ни одна проверка прав её не учитывает.
14. **Утверждение «прогнал все страницы под тестовым пользователем» невоспроизводимо.** Тестов и CI в репозитории нет, проверка была ручной и одноразовой.

### Низко
15. Шрифт Inter грузится с rsms.me: внешняя зависимость для внутреннего портала.
16. `secretHint` для DataForSEO показывает 4 первых символа логина и 4 последних пароля.
17. Истёкшие сессии из таблицы `Session` никогда не удаляются.
18. Админ может указать `baseUrl` провайдера на внутренний адрес сервера (SSRF). Риск низкий, доступ только у админа.
19. В `createBinding` удаление старого правила и создание нового не в транзакции.
20. Nginx-include использует `location ~ ^/` регуляркой вместо `location /`; работает, но может конфликтовать с правилами FASTPANEL для статики.

## Что сделать в первую очередь
1. Убрать `--accept-data-loss`, перейти на `prisma migrate deploy`, настроить ежедневный `mysqldump` с хранением вне сервера.
2. Включить принудительный HTTPS в FASTPANEL, добавить HSTS и остальные заголовки, выключить `poweredByHeader`.
3. В сиде оставить `update: {}` для провайдеров и разделов, чтобы правки админа сохранялись.
4. Для провайдеров без списка моделей делать проверку ключа дешёвым chat-запросом, а не `GET /models`.
5. Закоммитить `package-lock.json`, завести приватный удалённый репозиторий, поставить Node на Mac.
6. Сохранить `APP_ENCRYPTION_KEY` в менеджере паролей.
7. До переноса сервисов из Lovable выбрать модель размещения инструментов (пути или поддомены с общей cookie).
